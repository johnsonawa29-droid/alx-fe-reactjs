# alx-fe-reactjs # React Query Data Fetching Demo

This project demonstrates how to use React Query to fetch, cache, and refetch data from an external API.

## Features
- React Query setup with QueryClientProvider
- Data fetching from JSONPlaceholder API
- Query caching
- Manual data refetch interaction

## Tech Stack
- React
- React Query (@tanstack/react-query)
- Vite
