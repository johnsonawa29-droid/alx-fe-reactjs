# React Query Demo

A simple React application demonstrating advanced data fetching, caching, and updating using **React Query**. This project uses the **JSONPlaceholder API** to fetch posts and showcases efficient API interaction and UI responsiveness.

---

## 🚀 Features

- Fetch posts from a public API (`https://jsonplaceholder.typicode.com/posts`)
- Display posts with **loading** and **error handling**
- **Caching** with React Query – navigate away and return to see instant data load
- **Manual refetch** – update posts on demand using a button
- Optional integration with **React Query Devtools** for cache inspection
